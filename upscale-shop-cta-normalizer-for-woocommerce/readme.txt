Normalize WooCommerce shop button labels and styling so Add to cart / Select options / Read more feel consistent.

== Description ==

Confused shoppers bounce when product cards mix different call-to-action labels. Upscale Shop CTA Normalizer for WooCommerce lets you set clear labels per product type and optionally unify loop button styling.

**Requires WooCommerce.**

== Installation ==

1. Upload to `/wp-content/plugins/upscale-shop-cta-normalizer-for-woocommerce`
2. Activate
3. Open **WooCommerce → CTA Normalizer**
4. Set labels and save
