Diagnose “site broke after an update” issues with a health snapshot, newest active plugins list, and a change log of updates/activations.

== Description ==

When a site breaks after plugin or theme updates, you need a calm checklist — not guesswork.

**Plugin Conflict Reporter** adds a Tools screen that shows:

* WordPress / PHP / theme snapshot
* Active plugins sorted by newest file time
* A log of plugin/theme/core updates and activate/deactivate events

Use it on staging first. Deactivate newest suspects one at a time.

== Installation ==

1. Upload to `/wp-content/plugins/plugin-conflict-reporter`
2. Activate
3. Open **Tools → Conflict Reporter**
