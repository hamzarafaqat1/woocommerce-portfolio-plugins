# WooCommerce Portfolio Plugins

Original WooCommerce / WooCommerce Subscriptions sample plugins by **Hamza R.**

Each folder is a standalone WordPress plugin you can copy into `wp-content/plugins/`.

## Plugins

### WooCommerce Subscriptions
| Folder | Description |
|--------|-------------|
| `wc-subscriptions-member-documents` | Versioned templates, acceptance, PDF archive, email, migration, tests |
| `wc-subscriptions-renewal-reminders` | Pre-renewal reminder emails |
| `wc-subscription-content-gate` | Members-only content |
| `wc-subscriptions-bulk-tools` | Admin CSV export of subscriptions |
| `wc-subscriptions-activity-log` | Lifecycle activity log |

### WooCommerce
| Folder | Description |
|--------|-------------|
| `wc-checkout-field-extras` | Checkout VAT + delivery fields |
| `wc-low-stock-alerts` | Low stock email alerts |
| `wc-order-export-csv` | Order CSV export |
| `wc-product-quick-duplicate` | Quick duplicate products |
| `wc-role-based-pricing` | Role / wholesale pricing |

### WordPress.org–ready (pain-point plugins)
| Folder | Description |
|--------|-------------|
| `hamza-mobile-spacing-fix-for-elementor` | Cap Elementor mobile padding/margins/spacers |
| `hamza-shop-cta-normalizer-for-woocommerce` | Consistent shop CTA labels + button styling |
| `hamza-conflict-reporter` | Update/activation log + conflict health snapshot |

Each includes `readme.txt` + `uninstall.php`. Names avoid trademark-leading terms for directory review.
