Fix oversized Elementor padding and margins on mobile so pages stop looking broken on phones.

== Description ==

Upscale Mobile Spacing Fix for Elementor helps when desktop spacing looks fine but phones show huge gaps, tall spacers, or uneven section padding.

**Features**

* Cap section padding on small screens
* Normalize widget margins on mobile
* Optionally collapse tall Elementor spacers
* Configurable breakpoint
* Lightweight CSS-only front end

Works best on Elementor-built pages.

== Installation ==

1. Upload the plugin folder to `/wp-content/plugins/upscale-mobile-spacing-fix-for-elementor`
2. Activate via **Plugins**
3. Go to **Settings → Elementor Mobile Spacing**
4. Adjust limits and save

== Frequently Asked Questions ==

= Does this replace Elementor responsive controls? =

No. It adds a safety net when inherited desktop spacing is too large on mobile.

= Will it affect desktop? =

No. Rules apply only below your chosen breakpoint.
