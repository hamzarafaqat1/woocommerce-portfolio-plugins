# WC Subscriptions Renewal Reminders

Sends a daily-scanned reminder email N days before a WooCommerce Subscriptions renewal.

## Features

- Daily cron scan of active subscriptions
- Configurable “days before” setting
- Per-renewal-date meta so members are not spammed

## Requires

WooCommerce + WooCommerce Subscriptions
